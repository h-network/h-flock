## Two things worth writing down

⚠ **A pasted message is executed** in a CLI-less window. `[message from alice] …`
became `bash: [message: command not found`, which is the correct outcome and not
a fault — with no TUI there is nothing to absorb the keystrokes. **The check is
that the text arrived**, so the script greps the pane rather than reading its
exit status.

⚠ **Two apparent failures were the harness, not the system.** Both used `tail -5`
on a captured pane, which returned the blank lines *below* the prompt rather than
the message above it. Verified by hand before concluding anything — the
distinction between a broken system and a broken test is the whole reason to
look rather than to re-run.
